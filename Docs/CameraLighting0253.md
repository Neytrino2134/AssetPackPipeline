# Ключевой свет со стороны камеры — 0.25.3

Overview ранее создавал DirectionalLight с Pitch=-45, Yaw=60, освещая заднюю
сторону при камере на +Y. Теперь используется Pitch=225, Yaw=60, Roll=0 в
стандартном ракурсе — как указанный пользователем наклон 225° на скриншоте.
Это направление лучей вниз от стороны камеры с боковым углом 30°.
Unreal может показывать эквивалентное нормализованное представление углов.

lighting.key_rotation задаёт единую схему. Для отдельных ассетов media.advance
применяет её относительно фактического yaw камеры на каждом ракурсе, включая
MID, LOW, выбранные LOD и автоматический LOD review. Интенсивность света,
положение камеры, экспозиция, текстуры и материалы не изменяются.

overview.build использует новый свет сразу. overview.open_map обновляет
принадлежащий пайплайну KeyLight в старых сценах и сохраняет карту; поэтому
изменение применяется также при рендере уже подготовленных Overview.
Готовые PNG нужно перерендерить после перезапуска редактора.

Проверено в UE 5.8.4 / NullRHI на изолированной копии:
обновление старого света, направление лучей вниз со стороны обзорной камеры,
шесть дополнительных поворотов камеры и повторное применение без изменений.
126 unittest прошли. GPU-рендер в этой проверке не выполнялся.
