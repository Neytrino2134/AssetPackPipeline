# Простая обтекаемая коллизия — 0.29.0

Player Collision и Visibility Collision — режимы визуализации разных запросов,
а не два независимых меша, которые обязательно создаются отдельно. Pawn/Character
обычно перемещается капсулой и использует simple collision; выбор геометрии для
лучевых запросов также зависит от trace_complex и Collision Complexity.
Наличие формы не гарантирует блокирование: важны Collision Enabled и ответы
компонентов (например, BlockAll / Block для Pawn), включая настройки персонажа.

Раньше пайплайн удалял прежние формы и создавал один Box. Теперь Быстрый старт
и Мастер выбирают convex: штатный Auto Convex Unreal / V-HACD. Значения по умолчанию:
максимум 8 оболочек, 16 вершин на оболочку, точность 100000. Прямоугольная форма
может остаться похожей на коробку — для контейнера это нормально; камни и арки
аппроксимируются выпуклыми частями. Это простая collision-геометрия, не замена
видимого меша и не Complex As Simple. Используется Simple And Complex.

Глобальные параметры в профиле:

```json
{
  "collision": "convex",
  "convex_collision": {
    "hull_count": 8,
    "max_hull_verts": 16,
    "precision": 100000
  }
}
```

В профессиональных формах есть выбор convex / box / none и три параметра Convex.
Для отдельной модели можно переопределить collision; бюджеты общие для профиля.
Старый профиль с явно указанным box не переписывается при загрузке:
выберите convex и нажмите «Обновить материалы и настройки без импорта мешей» /
«Применить настройки к существующим ассетам». Обновите обзорные сцены и PNG после этого.
В быстрых режимах используется новый convex по умолчанию. Обновлены примерные профили.

Не меняйте параметры без просмотра результата для арок/дверей/узких проходов:
слишком грубая декомпозиция может закрыть отверстие. Для сложных форм подберите
больше оболочек/точность или подготовьте ручной UCX-коллайдер отдельным процессом.
Пайплайн не обещает автоматическую проверку всех проходов для капсулы игрока.
При неудаче Auto Convex фиксируется ошибка; скрытого отката на Box нет.

Read-back учитывает convex отдельно от примитивов: Unreal get_simple_collision_count
считает Box/Sphere/Capsule, а get_convex_collision_count — выпуклые оболочки.
В отчёте simple_collision_count означает их сумму. Проверки чистого проекта
используют ту же сумму; изменение бюджета Convex аннулирует incremental receipt.
Аудит перед рендером проверяет точку внутри оболочки, а не потенциально пустой
центр арки; центр безопасно вычисляется нативным helper без доступа Python к
закрытым VertexData.

Проверено UE 5.8.4 в изолированном проекте: настоящий камень Fantasy_Stone_01_01,
копии LOD и MID/Nanite контейнера, полная runtime._settings, сохранение числа
треугольников и режима Nanite, convex read-back, блокирующий capsule sweep и
ответ Pawn=Block. На камне получено 8 оболочек без Box. Три трассировки аудита
попали в нужный актёр. Это не запуск настоящего игрового Character/PIE.
151 unittest, Custom UI и нативная сборка прошли. См. Verification0290.json.
Исходные FBX и рабочий Content пользователя не изменялись.
