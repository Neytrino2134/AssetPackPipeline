# Итоговый вывод 0.25.1

Структура внутри выбранного пользователем каталога (либо прежнего каталога Saved):

```text
FinalProject/
  2026-11-02_15-04-07/
    MyPack_Project/
      MyPack.uproject
      Config/
      Content/MyPack/
    MyPack_Project.zip
    MyPack_Renders/
      Overview_All_Meshes.png
      MESH_MID_01_01.png
      MESH_LOW_01_01.png
      MESH_LOD1_01_01.png
      MESH_MID_01_01_View_02.png
      manifest.json
      sources.json
    MyPack_Renders.zip
```

Время локальное, на момент создания итогового каталога. Коллизии в одну секунду
получают суффиксы _02, _03. Повторный запуск всегда создаёт новый каталог.
Внешняя папка проекта получает _Project; имя .uproject и папка Content сохраняют
прежнее общее имя, пути Unreal-ассетов не переименовываются.

Вывод только рендеров использует такую же структуру, без проекта и его ZIP.
Рендеры всех запусков собраны в одну плоскую папку и один ZIP; UUID-подпапок нет.
MID означает Nanite, LOW — LOD0, LOD1/LOD2… — соответствующий уровень.
Числовой хвост ID модели сохраняется (Pack_01_01 → 01_01); при отсутствии хвоста
используется порядковый номер. Конфликтующие имена получают числовой суффикс.
Первый ракурс без суффикса, дополнительные — View_02 и далее.
Повторные обзорные снимки получают _02, _03; обзор LOD — Overview_LODs.

manifest.json содержит SHA256 экспортированных PNG. sources.json сохраняет
соответствие новым именам: исходный файл, модель и ID запуска. Служебные папки
запусков в Saved сохраняют ID; изменения касаются итогового пользовательского вывода.
Внутренние подписи на изображениях, меши, камеры и качество рендера не меняются.
Без запрошенных изображений папка и ZIP рендеров не создаются.
Старые поставки автоматически не переносятся и не переименовываются.
