# 0.18.0 — итоговая поставка и очистка импортированного пака

В Быстром старте теперь есть блок 4 «Итоговая поставка». В Мастере он находится
на четвёртом шаге, в Профессиональном режиме — на вкладке «Поставка».
Настройки общие: каталог вывода и флажок автоматического выпуска ZIP (включён).
Пустой каталог использует Saved/AssetPackPipeline/Deliveries. Каждый запуск создаёт
новую папку FinalProject/ГГГГ-ММ-ДД_ЧЧ-ММ-СС, не перезаписывая старые поставки.
Быстрый старт и Мастер прокручиваются, как профессиональные формы.

Полный запуск: импорт всех выбранных представлений → проверка → обзорные карты →
выбранные изображения → один чистый проект → отдельный Unreal для технической проверки
→ ZIP проекта → копии готовых PNG в ИмяПака_Renders и ИмяПака_Renders.zip рядом с ZIP проекта.
Это два архива: Content-проект отдельно, изображения отдельно. Исходные PNG остаются
в папках запусков, в итоговой папке сохраняется manifest.json с SHA256.
При отключённых рендерах папка/ZIP Renders не создаются.
Неуспешная проверка чистого проекта блокирует ZIP. Ошибки не превращаются в успешную
поставку и не исключают меши молча. Fab-публикация и художественная приёмка не выполняются.

Кнопка «Запустить этап 4 для подготовленных мешей» позволяет повторить только поставку.
В простых режимах используются текущие параметры мастера; в профессиональном —
текущий профиль и необязательный «Профиль второго типа LOD / Nanite».
В профессиональном режиме готовые кадры выбираются через существующее поле Run ID
предметных кадров (также принимает Run ID общего превью). Разрешены только passed
запуски этого же пака. В простых режимах переиспользуются кадры предыдущей завершённой
последовательности этого окна, если совпадает пак и корень Content.
После перезапуска редактора IDs кадров можно задать в профессиональном режиме.
Изменённую геометрию следует рендерить заново: копирование старых PNG не обновляет их.
Окно нужно держать открытым до окончания всех этапов.

## Очистка текущего проекта

«Очистить импортированный пак…» показывает полный план: что удалить и что сохранить,
включая причины. Область — каталог выбранного пака в /Game. Удаляются только объекты
с метаданными принадлежности AssetPackPipeline и совпадающим pack_id: меши, материалы,
инстансы, текстуры и сгенерированные карты. Объекты без метки остаются.
Текущая карта не удаляется; зависимости открытой карты, чужих ассетов и внешних карт
сохраняются транзитивно. Для полной очистки сначала откройте L_Presentation.
Перед очисткой все изменения нужно сохранить; PIE и активные задачи блокируют операцию.

После просмотра плана нажмите удаление и подтвердите. План повторно сравнивается
непосредственно перед удалением. Резервная копия пакетов, plan.json и result.json
сохраняются в Saved/AssetPackPipeline/ImportedCleanup/<id>. Исходные FBX/GLB, текстуры
на диске, поставки и рендеры не удаляются. Автоматической очистки после ZIP нет.
Резервная копия предназначена для восстановления файлов при закрытом редакторе;
автоматическое восстановление пока не реализовано.

Проверка блока: 97 unittest, включая запрет ZIP после проваленной верификации,
порядок этапов, копирование только перечисленных PNG и отклонение выхода из папки
рендера; реальное создание Tk-окна и доступность элементов с прокруткой.
Полный новый импорт/поставка и удаление настоящих ассетов в Unreal в этом блоке не
запускались. Используются существующие проверка чистого проекта и упаковка delivery API.
