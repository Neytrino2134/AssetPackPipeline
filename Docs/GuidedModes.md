# Режимы окна — 0.17.0

UEFN Source отложен. Разработка продолжается для обычного Unreal Editor.

По умолчанию открывается **Быстрый старт**: папка исходников, имя пака, FBX/GLB,
состав LOD + MID/Nanite и изображения. Все модели из каталога; старый фильтр
asset_ids и индивидуальные overrides не переносятся в простой запуск.
Выбирайте имя пака латиницей. Настройки материалов и screen sizes берутся из
загруженного профессионального профиля. Выбор папки не анализирует её автоматически:
нажмите «Проверить исходники» до запуска.

**Мастер** показывает те же параметры последовательно: исходники → состав →
изображения → обзор плана. Это локальный детерминированный мастер, без AI-запросов.
**Профессиональный** сохраняет прежние вкладки. «Результаты» открывает журнал
в профессиональном режиме. Переключение режимов не отменяет текущую задачу.

«Подготовить меши и сцены» создаёт отдельные JSON в Saved/AssetPackPipeline/UI/Guided,
проверяет исходники обеих версий, затем запускает импорт, проверку ассетов и создание
раздельных обзорных карт. Обе версии находятся в одном корне Content с общими
материалами и текстурами. Источник Nanite AUTO: MID, иначе HIGH.

Изображения независимы: один общий кадр (по умолчанию), каждый MID, каждый LOW
(LOD0), все LOD, выбранный LOD каждой модели. Повторяющиеся номера LOD объединяются.
Несовместимый выбор, например кадры MID при импорте только LOD, выдаёт ошибку.
Без отметок изображения не создаются.

Контроллер работает на потоке редактора, через тот же API, что и MCP. Следующий
этап запускается только после passed предыдущего. Геометрические замечания не
исключают источники (warn); технический сбой этапа останавливает последовательность.
Кнопка «Остановить» отменяет будущие этапы и просит текущую задачу завершиться.
Окно следует держать открытым до завершения последовательности.

Граница текущего блока: подготовленные меши, материалы, сцены и выбранные кадры.
Выпуск чистого проекта, его проверка и ZIP пока запускаются через профессиональную
вкладку «Поставка». Успех подготовки не означает принятие Fab.

Следующий блок: встроенный чат OpenAI, безопасная конфигурация ключа вне профилей,
выбор «только совет / предложить действия / выполнять разрешённые операции»,
журнал действий и использование ограниченного набора pipeline API вместо произвольного
Python. Сетевые запросы вне редакторского потока; UObject-операции только в Slate tick.
API-ключи и история приватного чата не входят в поставку ассетов/плагина.

Проверки текущего блока: 85 unittest прошли; Tools/smoke_guided_window.py создаёт
реальное Tk-окно и переключает три режима и четыре шага. Это не подтверждает
живой импорт внутри Unreal: такой прогон и AI-интеграция ещё предстоят.

Обновление 0.17.1: чат реализован в режиме Мастер. Актуальная настройка, права и границы проверки — OpenAI_Assistant.md. Live API ещё не проверен.
