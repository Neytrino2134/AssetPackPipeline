# 0.20.0 — второй блок переноса на Slate

Без Tkinter: три режима, четыре шага мастера, выбор FBX/GLB и LOD/MID,
общего кадра/каждого MID/LOW/всех или выбранного LOD; финальная поставка.
В профессиональном режиме используется JSON-редактор профиля, а не прежние
подробные формы вкладок. Непустой JSON применяется только в профессиональном режиме.
Подробные нативные профессиональные формы ещё предстоят.

Content: сканировать → выбрать папку → показать план (ниже в статусе) →
подтвердить удаление. Подтверждение — нативный диалог Unreal. Python повторно
проверяет совпадение папки и пакетов, внешние ссылки и чистоту редактора.
Резервная копия, plan/result: Saved/AssetPackPipeline/Native/Cleanup/<id>.
Действие очистки не предоставлено AI.

OpenAI: скрытое поле нового ключа, список моделей, запоминание через DPAPI,
проверка ключа/загрузка доступных моделей, чат-советник. Ключ очищается из поля при
применении и передаётся Python через окружение процесса; не включается в JSON
команды/файлы статуса. Окружение может быть доступно другому коду того же процесса.
Нажмите «Применить настройки» перед проверкой ключа. Пустое поле использует текущий
ключ процесса/сохранённое подключение. Чат отправляет текст в OpenAI по кнопке;
запросы фоновые, результаты обрабатываются Slate tick. Ответ отображается в
нижнем статусе; отдельная панель полной истории и выполнение действий AI пока не перенесены.

Открытый Unreal держал текущий DLL. Он не закрывался и его содержимое не менялось.
Сборка выполнена в Saved/NativePackage020/HostProject, результат Succeeded.
Архив 0.20.0 использует новый бинарник этой изолированной сборки, а не заблокированный
старый DLL основного проекта. Установка: закрыть Unreal, заменить папку плагина
из архива, открыть проект. UE 5.8.4 / Windows; другие версии требуют пересборки.

Проверки: 97 unittest; изолированный настоящий UnrealEditor-Cmd с nullrhi/unattended,
десять циклов открытия/закрытия новой панели: passed=true, tkinter_loaded=false.
Результат: Saved/NativePackage020/HostProject/Saved/AssetPackPipeline/NativeSmoke.json.
Живой запрос с пользовательским ключом, удаление реального Content и длительный
интерактивный прогон с вводом/IME не выполнялись. Устранение всех крашей не заявляется.
