# 0.21.0 — профессиональные Slate-формы

В режиме «Профессиональный» добавлены поля вместо обязательного JSON-редактирования:

- Content root, выбранные IDs, MeshInfo, относительная папка текстур.
- Screen sizes LOD, источник Nanite AUTO/MID/HIGH, простая коллизия.
- Roughness, Metallic, Normal Strength, UV Scale, ORM.
- Столбцы, расстояние и подписи обзорной карты.
- Размер кадра и прогрев; pitch, FOV, запас кадрирования и экспокоррекция предметных кадров.

«Загрузить активный профиль в редактор JSON» теперь заполняет также формы,
папку исходников, имя пака и формат. Формы используют JSON как базу для сохранения
неизвестных/индивидуальных настроек, но видимые значения форм имеют приоритет.
JSON получает полный приоритет только при явном флажке «Служебный режим».
В простом режиме и мастере профессиональный JSON не применяется.

«Сохранить активный профиль» сохраняет первый выбранный тип представления в
Saved/AssetPackPipeline/active_profile.json. Общие поля используются для генерации
обоих представлений. Сохранение требует корректных настроек и существующей папки
исходников, но не запускает импорт и не требует завершения анализа исходников.
«Проверить импортированные ассеты» использует существующую проверку API.
«Применить настройки к существующим ассетам» запускает start_settings, без импорта геометрии.
При активной задаче новые операции блокируются. Некорректные параметры отклоняются
перед запуском (диапазоны материалов, LOD, размеры PNG, камера, папка назначения).

Ещё не перенесены формы overrides по отдельной модели, диагностики, очереди и пролётов;
соответствующие поля профиля сохраняются через базовый JSON. AI остаётся советником.
Нативный журнал пока показывает последний ответ/состояние, а не полную историю.

Сборка UE 5.8.4 успешна в изолированном HostProject, текущий редактор не закрывался.
101 unittest, включая roundtrip профессиональной формы, сохранение неизвестных полей,
выбор всех моделей при пустом IDs и отклонение неверных параметров.
Полный импорт/применение настроек и живой OpenAI не запускались. Короткая проверка
Slate lifecycle не заменяет длительную работу в интерактивном редакторе.
