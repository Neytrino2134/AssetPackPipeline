# 0.22.0 — индивидуальные настройки, очередь, диагностика

В профессиональном режиме добавлены нативные поля индивидуальной модели:
ID, screen sizes, источник Nanite, коллизия, Remove Degenerates, Roughness,
Metallic, Normal Strength, UV Scale, ORM. Пусто/inherit наследует общие настройки,
ORM «-» отключает индивидуальную ORM. Количество LOD менять нельзя.
Кнопки загрузки, записи и удаления работают с профилем UI. Для записи на диск
затем нажмите «Сохранить активный профиль». Внутренние значения JSON сохраняются.

Очередь показывает до 50 последних импортов/settings_update. Выберите Run ID,
откройте отчёт или возобновите задачу. Совместимость/снимок исходников проверяет
api.resume; готовые и несовместимые запуски не возобновляются.
Отчёт и состояние показываются в нижней области. Возобновлённая задача отслеживается
независимо от открытой вкладки; «Остановить» использует текущий активный run.

Диагностика исходников анализирует FBX/GLB без импорта, для каждого выбранного типа.
Диагностика импорта использует первый LOW/LOD профиль и существующую изолированную
служебную область API; это реальный тестовый импорт. Для Nanite доступен анализ
исходников, сравнение Remove Degenerates требует LOW/LOD.

Уточнено отслеживание открытого SDockTab: weak reference на экземпляр, возвращённый
TryInvokeTab, вместо поиска через общий TabManager. Проверка больше не зависит
от того, как TabManager учитывает вкладку в текущем layout.

Проверено: 103 unittest; успешная C++ сборка в отдельном HostProject; настоящий
UnrealEditor-Cmd с nullrhi — чтение очереди и профиля, 10 циклов открытия/закрытия,
passed=true, bridge_readonly=true, tkinter_loaded=false.
Доказательство: Saved/NativePackage020/HostProject/Saved/AssetPackPipeline/NativeSmoke.json.
Индивидуальные настройки проверены pure-Python тестами; применение к реальным ассетам,
возобновление настоящего импорта и диагностический импорт в этом проходе не запускались.
Существующий контент и текущая пользовательская сессия не изменялись.

Остаются native подтверждения действий AI, полная история/журнал, формы пролётов,
длительный интерактивный прогон стабильности. AI по-прежнему только советник.
Установка: закрыть Unreal, заменить папку плагина из архива 0.22.0, открыть UE 5.8.4.
