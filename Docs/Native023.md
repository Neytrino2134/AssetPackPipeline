# 0.23.0 — завершение основного нативного блока

## История и AI

В Slate добавлены отдельные read-only области истории чата и журнала задач.
Чат/настройки OpenAI, очистка Content и журнал раскрываются по кнопке, не перегружая
быстрый старт. Выбранная и применённая модель восстанавливается при открытии панели.
Обновление импорта больше не затирает ответ помощника. Хранятся последние 200
сообщений/событий; контекст Responses API живёт в памяти текущей сессии редактора.
Закрытие вкладки не сбрасывает диалог и задачи. Для нового диалога — «Очистить историю».
Снимок видимой истории/журнала записывается локально в Saved/AssetPackPipeline/Native/state.json;
полный API-контекст после перезапуска редактора не восстанавливается.
API-ключи редактируются только в специальном скрытом поле; известный ключ и строки
формата sk-* удаляются из сообщений перед отправкой и из видимого журнала.

Режимы AI: советы / подтверждать действия / автоматически. По умолчанию только советы,
инструменты в этом режиме не предоставляются API. Разрешены только проверка исходников,
запуск подготовки с текущими настройками, чтение статуса и остановка. Произвольного
Python, удаления Content, публикации и произвольного изменения настроек агенту нет.

Каждое сообщение фиксирует снимок параметров UI. Предложение показывает его локально.
«Подтвердить» вызывает отдельный native диалог Unreal; действие выполняется со снимком,
даже если после сообщения пользователь изменил поля. Для другого снимка отклоните
предложение и отправьте новый запрос. «Отклонить» не выполняет действие.
В автоматическом режиме подтверждения нет. Лимит — 6 вызовов инструментов на сообщение.
Результаты инструментов возвращаются модели; асинхронный запуск не объявляется
завершением импорта. Пока идёт HTTP-запрос или ожидает предложение, новый запрос блокируется.
«Остановить» отменяет будущие действия/предложение и просит текущую задачу остановиться.
Уже отправленный HTTP-запрос может завершиться, но его отменённый ответ не исполняется.
Сетевые операции вне editor thread, UObject/Slate операции только на editor thread.

## Пролёты

В профессиональном режиме есть длительность, FPS, ширина/высота, начальный/конечный
ракурс, pitch и FOV. Настройки валидируются перед запуском. Кнопка создания/рендера
пролёта работает с первым выбранным профилем через существующий api.start_flythrough.
MRQ-кадры остаются в Saved/AssetPackPipeline/Flythrough/<run_id>. Это отдельная
операция; обычный финальный ZIP включает выбранные общие/предметные PNG, не видео.

## Стабильность

Найден и исправлен повторный вход контроллера последовательности из Slate tick
во время запуска импорта. Повторный callback больше не начинает следующий этап
до возврата из текущего. Есть отдельный регрессионный тест. Добавлена такая же защита
в native bridge poll. Нативный UI не создаёт Tkinter.

## Проверки блока

- 113 unittest: настройки/переопределения/пролёты, инструменты AI, подтверждение и
  отказ, снимок параметров, запрет неизвестных команд, поздний отменённый ответ,
  редактирование секретов, повторный вход tick и защита упаковки.
- Настоящий UE 5.8.4 с RHI: Containers, 10 моделей × LOD/MID = 20 мешей; материалы,
  5 LOD, реальные Nanite source triangles; один общий PNG 1280×720, визуально проверен.
- Чистый проект проверен отдельным Unreal, fresh_project_verification=passed.
  ZIP содержит 10 _LODS и 10 _MID, ZIP integrity check пройден.
- Готовые PNG и Renders.zip созданы рядом с ZIP проекта.
- После проверки удалены 55 собственных тестовых ассетов, retained_count=0,
  с резервной копией. Основной пользовательский проект не изменялся.
- Реальный короткий MRQ-пролёт: 2 секунды × 12 FPS, получены 24 из 24 PNG, passed.
- Длительный native widget soak: см. итоговый Verification.json в Docs/Native023
  основного workspace. Это программная проверка, не эмуляция настоящего IME.

Live OpenAI не проверен: в доступном окружении/локальном хранилище ключ не найден.
API transport и подтверждения проверены тестами с подменой сетевого ответа; это
не заменяет запрос с пользовательским ключом. Ручной IME/Alt-Tab пока не проверен.
Готовность Fab не заявляется; художественная приёмка по-прежнему отложена.

Установка: закрыть Unreal и заменить папку плагина из архива. Бинарник для UE 5.8.4
Windows; для других сборок UE нужна пересборка. Старое Tk-окно не используется.
