# Native migration checkpoint — 0.19.0

Первый рабочий блок устранения Tk из процесса редактора. Пункт меню ui.open_window
теперь вызывает UAssetPackPipelineNative.OpenWindow — C++ Slate SDockTab. Tk fallback
отключён. Старые Tk-классы сохранены только для переноса/офлайн-сравнения; их обычный
entry point тоже перенаправлен на native и не создаёт Tk.

Нативная панель: выбор папки исходников, pack_id, формат FBX/GLB, LOD/MID,
один общий кадр, флажок проверенного ZIP и каталог вывода; план, запуск, остановка.
Профессиональные настройки временно через JSON-поле (загрузка активного профиля).
Непустой JSON имеет приоритет над полями источников/вариантов; флажки общего кадра
и финальной поставки остаются командами текущего запуска.
Существующие Python API и MCP не заменены; пакетирование/проверка используют guided.Session.
Native bridge регистрирует свой Slate tick независимо от жизни вкладки. Закрытие
вкладки не прерывает последовательность; используйте «Остановить».
Состояние: Saved/AssetPackPipeline/Native/state.json. Ключей/истории AI в этом файле нет.

Это не полный перенос всех функций 0.18.1. Ещё предстоят:

- Три полноценных native режима, подробные формы профессиональных настроек.
- Выбор всех вариантов рендеров и пошаговый мастер.
- Native AI settings/chat (Python transport и шифрование уже существуют).
- Native Content scanner / план очистки / подтверждение удаления.
- Длительный интерактивный прогон: ввод RU/EN, IME, Alt-Tab, resize, диалоги,
  импорт/рендер и закрытие вкладки во время запроса/задачи.

Сборка: VS 14.44 / Windows SDK 10.0.26100.0 / UE 5.8.4. Build.bat завершился
Succeeded. В текущем проекте установлен скомпилированный DLL. Для загрузки нового
модуля в уже запущенном редакторе нужен перезапуск. Не выполнять hot reload Tk-классов.
Архив теперь включает Binaries/Win64 DLL и .modules (без PDB/Intermediate). Бинарник
предназначен для этой установленной сборки UE; другие версии требуют пересборки.

Проверки: 97 unittest; Tools/smoke_native_ui.py выполнен настоящим UnrealEditor-Cmd
с nullrhi/unattended: 10 циклов OpenWindow/IsWindowOpen/CloseWindow,
tkinter_loaded=false, passed=true. Доказательство: Saved/AssetPackPipeline/NativeSmoke.json.
Это проверка Slate lifecycle в Unreal без GPU, а не визуальная/длительная проверка
в пользовательском окне. Контент не импортировался/удалялся, платных API-запросов не было.
Прежние краши не объявляются полностью исправленными до длительного прогона.
