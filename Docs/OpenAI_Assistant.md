# Помощник OpenAI — 0.17.2

## Настройки через окно (актуально с 0.17.2)

Кнопка «Настройки AI…» доступна в верхней панели любого режима и в чате мастера.
Введите ключ в скрытое поле, выберите модель, нажмите «Применить» — перезапуск
редактора не требуется. Пустое поле сохраняет текущее подключение; сохранённый
ключ никогда не подставляется в виджет. Ключ можно использовать только до закрытия
Unreal или поставить «Запомнить ключ на этом компьютере». Во втором случае он
сохраняется зашифрованным Windows DPAPI для текущего пользователя.

Настройки находятся вне проекта: %LOCALAPPDATA%/AssetPackPipeline/ai-settings.json.
В JSON только ID модели и зашифрованный blob. Файл не переносится вместе с плагином.
Приоритет подключения: новый ключ сеанса → сохранённый ключ → OPENAI_API_KEY.
«Забыть ключ» очищает локальное хранение и ключ сеанса; переменную окружения не меняет.
Ключ, применённый без запоминания, заменяет предыдущий сохранённый ключ и убирает его
из локального хранилища. Защита DPAPI не мешает другим программам того же пользователя
расшифровать данные — это защита хранения, а не изоляция от скомпрометированного аккаунта.

Готовое меню на 31.10.2026: gpt-6.1-sol, gpt-6-astra, gpt-6.1-terra, gpt-6-luna.
Официальный каталог: https://developers.openai.com/api/docs/models
«Проверить ключ / обновить модели» делает GET /v1/models в фоновом потоке, используя
введённый ключ, либо текущее подключение. Ключ при этом не сохраняется: для этого
нажмите «Применить». Меню показывает доступные ID известных семейств с поддержкой
инструментов, включая их датированные версии. Специализированные audio/image модели
отфильтрованы; произвольный ID можно ввести вручную. Сам /models не сообщает поддержку
конкретного API или tool calling: окончательная проверка — реальный запрос к модели.
Источник: https://developers.openai.com/api/reference/resources/models/methods/list

Проверено: 94 unittest; настоящий вызов Windows DPAPI с тестовой строкой,
проверка отсутствия открытого секрета в файле, расшифровка и удаление локального ключа;
создание Tk-диалога и меню. Настоящий пользовательский ключ не вводился, live OpenAI
и работа окна внутри Unreal ещё требуют проверки.

## Чат и режимы работы

Откройте окно плагина → «Мастер». Внизу находится чат. Модель API можно поменять
в поле «Модель API»; доступ определяется вашим аккаунтом. По умолчанию gpt-6.1-sol.
Для API требуется собственный доступ/баланс API, а не только подписка ChatGPT.

Альтернативный способ — OPENAI_API_KEY окружения процесса Unreal. Ключ не
записывается в JSON-профили и не входит в архивы. Задайте пользовательскую
переменную Windows через «Изменение переменных среды текущего пользователя»:
создать OPENAI_API_KEY, значение — ваш ключ. После изменения перезапустите Unreal;
при запуске из уже открытого Epic Launcher может потребоваться перезапустить и Launcher.
Не присылайте ключ в чат. Кнопка проверки в настройках проверяет доступ к списку моделей,
но не проверяет генерацию выбранной моделью.

Режимы разрешений:

- Только советы (по умолчанию): инструменты вообще не отправляются в API.
- Подтверждать действия: предложение показывается в чате, затем пользователь
  выбирает «Выполнить предложение» или «Отклонить». Статус читается автоматически.
- Автоматически: разрешённые действия выполняются без дополнительного вопроса.

Разрешены только check_sources, prepare_pack, status, stop. Эти действия используют
текущие настройки мастера и локальные скрипты. Нельзя менять настройки по произвольному
JSON, запускать код, читать произвольные файлы, удалять или публиковать ассеты.
Настройки берутся в момент выполнения действия; перед подтверждением проверьте окно.
Импорт идёт асинхронно, а status сообщает состояние. Автономного ожидания завершения
в облаке нет: после завершения можно попросить агента проверить статус новым сообщением.
Лимит — шесть вызовов инструментов на сообщение. «Остановить» отменяет будущие
AI-действия и последовательность подготовки; уже отправленный HTTP-запрос может
завершиться, но его ответ не запустит новые операции. Повторные HTTP-запросы автоматически
не выполняются. Таймаут — 90 секунд.

В OpenAI передаются сообщения и небольшой контекст: формат, состав мешей,
выбранные кадры/LOD, факт выбора папки, стадия и результаты разрешённых операций.
Исходные файлы, локальные пути и полные отчёты автоматически не прикладываются.
Не вставляйте секреты в сообщения. История чата хранится в памяти окна; store=false.
Названия операций и статусы записываются в локальный журнал окна.

Реализация: urllib без дополнительных pip-зависимостей, только HTTPS api.openai.com,
без перенаправлений авторизации. Запросы вне потока редактора, операции UI/Unreal
только в Slate tick. Строгая схема function calling + локальная проверка whitelist.
Основание: https://developers.openai.com/api/docs/guides/function-calling

Проверено: 90 unittest и создание настоящего Tk-окна с переключением режимов/шагов.
Запросы API в тестах подменены; live OpenAI и интеграция чата с импортом в Unreal
пока не подтверждены. Полный выпуск чистого проекта/проверенного ZIP всё ещё находится
в профессиональной вкладке «Поставка». Готовность Fab агент не утверждает.
