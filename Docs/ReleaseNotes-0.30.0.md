# MESHFLOW Asset Pack Pipeline v0.30.0

First published build since v0.27.1; it also contains the unpublished 0.28.0
(explicit Lit captures, optional diagnostic render modes) and 0.29.0 (fitted
Auto Convex collision) changes — see ReleaseNotes-0.28.0.md and -0.29.0.md.

## Custom UI
- Remembers window position/size (monitor-checked), maximised state, Pin, mode,
  tab, wizard step, Quick Start choices and unsaved profile edits between sessions
  (Saved/AssetPackPipeline/UI/custom_window.json). Profile files are not overwritten.
- New Pin button in the title bar keeps the window always on top.
- Dark scrollbars and table headers.
- MESHFLOW button on the Level Editor toolbar opens Custom UI.

## Rendering
- Quick Start: Wireframe and Player Collision images can be chosen per target
  (overview, each MID, each LOW); Lit images follow the «Изображения» selection.
- Brighter studio lighting (+1.8 EV over the profile exposure).
- Studio maps generated by the plugin are saved automatically, so they no longer
  block delivery, cleanup or the next overview with a «dirty map» error.
- Preview capture no longer re-checks map switching while capturing the current world.

## Fixes
- Quick Start/Wizard runs failed with «collision must be none or box»: the legacy
  scan check rejected the new convex default. Removed; covered by a test.
