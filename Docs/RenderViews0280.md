# Режимы рендера — 0.28.0

Основной режим Overview и индивидуальных PNG — «С освещением» (Lit).
Предыдущая версия наследовала режим редактора, кроме технического auto-LOD review.
Теперь режим явно устанавливается и считывается перед захватом; во время ожидания
снимка выбранный режим поддерживается. Исходный режим сохраняется один раз на
задание и восстанавливается при завершении, отмене и обработке ошибки.

В Быстром старте / Мастере блока «3. Изображения» два столбца:
слева — состав кадров (Overview, MID, LOW, LOD), справа — дополнительные режимы.
«С освещением — всегда» не отключается; каркасное, коллизия объекта и коллизия
игрока изначально выключены. Дополнительные режимы создают новые кадры каждого
выбранного вида изображения, а не заменяют основной. В Slate доступны те же флажки.

Настройка профиля: `previews.view_modes` — список из `lit`, `wireframe`,
`collision_visibility`, `collision_pawn`. Lit добавляется первым автоматически,
повторы исключаются. Режим коллизии объекта соответствует штатному Unreal
Visibility Collision, игрока — Player Collision. Это визуализация существующей
коллизии; дополнительные collision shapes не создаются и не исправляются.

Примеры итоговых файлов:

- Overview_All_Meshes_Lit.png
- Overview_All_Meshes_Wireframe.png
- MESH_MID_01_01_CollisionVisibility.png
- MESH_LOW_01_01_CollisionPawn.png

Все варианты сохраняются в прежнюю общую папку рендеров и один ZIP.
Старые отчёты без render_view сохраняют прежние имена при повторном экспорте.
В review.html индивидуальных изображений добавлен отдельный выбор режима,
чтобы сравнение LOD не смешивало Lit и диагностические кадры.
Технический automatic LOD telemetry остаётся только Lit: дополнительные
режимы для него явно отклоняются, поскольку они меняют проверяемый BasePass.

После обновления перезапустите Unreal/Custom UI и создайте изображения заново.
Готовые старые PNG не меняются. Native DLL пересобрана для UE 5.8.4 Win64.

Проверено 146 unittest, настоящий Custom UI во всех трёх режимах и при минимальном
размере окна, сборка и 10 циклов открытия/закрытия Slate без Tk в процессе Unreal.
В отдельной копии проекта на GPU выполнены 12 снимков: Overview, LOW и MID/Nanite
по четыре варианта. Все задания начинались из Wireframe; после каждого задания
Wireframe восстановлен. PNG проверены на размеры/SHA256; Lit и Wireframe
просмотрены визуально, включая более плотный каркас MID. См. Verification0280.json.
