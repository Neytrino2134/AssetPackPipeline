# Два интерфейса, один пайплайн

Репозиторий охватывает каталог плагина: Source, Content/Python, Profiles, Tests,
Config, Docs и Tools (упаковка, native smoke/soak, E2E, MRQ, сбор доказательств).
Бинарники, Intermediate, кэши, локальные профили, секреты и ZIP не
коммитятся. Проект Unreal, его Content и инструменты вне каталога плагина в этот
репозиторий не входят. Копии основных инструментов в Tools рассчитаны на установку
плагина в <Project>/Plugins/AssetPackPipeline; тестовые исходные ассеты и отчёты Saved
не входят в Git. Remote не настроен, публикация на GitHub не выполнялась.

Варианты будущего запуска:

1. Unreal UI — нативная вкладка Slate в процессе редактора (текущий вариант).
2. Custom UI — отдельный desktop-процесс с оформлением и компоновкой 0.18.1.
   Собственный mainloop и соединение с разрешёнными командами API в Unreal.

Tk 0.18.1 нельзя возвращать в процесс редактора, в Slate tick или Python Thread:
это возвращает область риска, найденную в отчётах abort. Можно сохранить внешний
вид и большую часть компоновки, но запускать GUI в отдельном процессе. Падение
GUI тогда не завершит процесс Unreal; ошибки самой операции Unreal всё ещё могут.

Рекомендуемый следующий блок реализации:

- Выделить host-independent клиент API для Custom UI; текущий window.py напрямую
  импортирует unreal, поэтому его нельзя просто запустить внешним python.exe.
- Узкий локальный RPC в Unreal, с одноразовой авторизацией и allowlist команд,
  без произвольного Python/eval/exec и без удалённого доступа по сети.
- Команды исполняются только на editor thread; внешний GUI использует свой mainloop.
- Настройки OpenAI/ключ остаются в пользовательском хранилище. Ключи не передаются
  через командную строку, репозиторий, профили или архивы.
- Два пункта меню: «Открыть Unreal UI» и «Открыть Custom UI». Общие run_id,
  профили, журнал и единая очередь. Второе окно не должно запускать параллельную
  подготовку, пока первое уже выполняет задачу.
- Проверить закрытие/падение Custom UI во время импорта и повторное подключение.

Реализовано в 0.24.0: оба пункта меню, внешний Custom UI, подписанная файловая RPC-очередь,
серверная последовательность задач и повторное подключение. Настройка и границы
проверки — CustomUI024.md. Старый Tk не создаётся внутри Unreal.
